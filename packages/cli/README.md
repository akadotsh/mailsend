# MailSend CLI

Send email through Cloudflare Email, MailerSend, Resend, or SMTP from the command line.

```sh
npm install --global @akadotsh/mailsend@beta
mailsend --help
```

See the [project documentation](https://github.com/akadotsh/mailsend#readme) for provider setup,
single-message examples, and bulk sending.

Requires Node.js 20 or later.
